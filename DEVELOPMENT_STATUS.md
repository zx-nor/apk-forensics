## Milestone 2 — implemented and tested
**Identification** (`identify/`): magic-byte table extended with TIFF and ISO-BMFF (`ftyp`).
`DeepIdentifier` refines RIFF into WAV/WEBP/AVI, ISO-BMFF into MP4/MOV/M4A/HEIC, and ZIP into
APK/AAB/JAR/DOCX/XLSX/PPTX/ODF/plain ZIP using internal structure. Reports extension mismatch
against the refined format, appended data (PNG after IEND, JPEG after last EOI with zero-padding
distinguished, PDF after last %%EOF with incremental-update detection, WAV beyond RIFF size),
and embedded signatures at non-zero offsets (streaming, overlap-safe; reported as leads only).

**ZIP** (`archive/`): EOCD and ZIP64 parsing; prepended-data offsets; choice of end record that
validates its directory (fake records inside comments are not trusted); local-header checks
(name, flags, method, bounds); path checks (traversal, absolute, drive letter, backslash, control
and bidi characters, duplicates, executable-type names reported as INFO only); symlinks described,
never followed; encryption identified (ZipCrypto, WinZip AES 128/192/256, PKWARE strong) and not
decrypted; bounded streaming inflate with real size and CRC measurement, compression-ratio check
(configurable), declared-vs-measured size check; nested archives inspected from bounded temporary
files that are deleted afterward, under depth and shared-budget limits.

**Metadata** (`metadata/`), each result has an explicit status:
EXTRACTED / NO_METADATA_PRESENT / EXTRACTION_FAILED / NOT_SUPPORTED.
- JPEG (JFIF, Exif, XMP subset, COM, frame info), PNG (IHDR, tEXt, zTXt, iTXt, eXIf, tIME, pHYs,
  CRC-verified), WebP (VP8/VP8L/VP8X, EXIF, XMP), TIFF/EXIF (IFD0, Exif, GPS with decimal
  coordinates, loop detection).
- PDF Info dictionary (classic trailer and xref stream; UTF-16 and PDFDocEncoding text; date with
  time-zone note). Encrypted PDFs are NOT_SUPPORTED; Info inside object streams is reported as not located.
- DOCX/XLSX/PPTX core, app, custom properties via hardened StAX (DTD and external entities disabled).
- MP3 (ID3v2.2–2.4 text/comment/picture, ID3v1, first MPEG frame), FLAC (STREAMINFO, Vorbis
  comments, PICTURE), WAV (fmt, data, LIST INFO, bext).
- MP4/MOV/M4A (ftyp, movie and track headers, codec, ilst and QuickTime text items, location);
  zero creation times reported as "not set", not as a date.
- APK: binary AndroidManifest decoded (package, version, SDK levels, permissions, components with
  exported and intent actions), signer certificates parsed (subject, issuer, serial, validity,
  SHA-256), v2/v3 signing block detected. Signatures are NOT cryptographically verified.
- SQLite header (page size, text encoding, user_version, application_id, version).

## Known limitations (do not treat as available)
- 7z and RAR: identified by signature only. No reliable library is available in this environment,
  so no listing or extraction exists.
- Encrypted OOXML (OLE compound containers) and encrypted archives are not analyzed for content.
- HEIC item metadata, AAB and ODF content, AVI: identified only.
- APK signatures are parsed, not verified. Permissions are reported as declared, never used to
  classify an app as malicious.
- XMP parsing is a subset of common simple properties.
- OpenPGP is not identified (its one-byte packet tag is too ambiguous).
- Embedded-signature hits are leads; they are not extracted or identified as content.
- Bitrate for MP3 reflects the first frame only.
- Scanning is bounded by `maxEmbeddedScanBytes`; very large files may be only partially scanned.
